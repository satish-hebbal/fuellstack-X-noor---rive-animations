# Drop your `.riv` files here

Anything in this folder ending in `.riv` shows up in the gallery automatically.
There is no list to maintain and no code to edit.

- **Filename becomes the title.** `loading-spinner.riv` → "Loading Spinner",
  `heroIcon_v2.riv` → "Hero Icon V2". Rename the file to rename the tile.
- **Tiles sort alphabetically** by title, with natural number ordering
  (`scene-2` before `scene-10`).
- **Restart `npm run dev` after adding files.** Vite scans this folder when the
  dev server boots, so new files need a restart to be picked up. Editing an
  existing file hot-reloads fine.

The sample files here are from Rive's public CDN — delete them once you've added
your own.
